## نحوه اجرا

هر فایل `.dart` را به عنوان `lib/main.dart` در یک پروژه Flutter قرار دهید و اجرا کنید:

```bash
# ایجاد پروژه جدید
flutter create student_app
cd student_app

# محتوای یکی از فایل‌های تمرین را در lib/main.dart کپی کنید
flutter run
```

یا اگر پروژه از قبل دارید، فقط محتوای فایل را جایگزین `lib/main.dart` کنید.
