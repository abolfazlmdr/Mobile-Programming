تمرین ۳: رابط کاربری ساده اندروید با Java و XML

این پوشه شامل فایل‌های اصلی نمونه است:
- MainActivity.java: منطق صفحه و واکنش به لمس دکمه
- activity_main.xml: عنوان، کادر ورود نام و دکمه

نحوه استفاده:
1) در Android Studio یک پروژه جدید با زبان Java بسازید.
2) اگر پروژه از AppCompat استفاده می‌کند، کد MainActivity.java را در Activity اصلی قرار دهید.
3) فایل XML را در مسیر app/src/main/res/layout/activity_main.xml جایگزین کنید.
4) مقدار package در MainActivity.java را با package پروژه خودتان هماهنگ کنید.
5) پروژه را اجرا کنید؛ نام را وارد و روی «ثبت نام» بزنید.

توجه: این پوشه فایل‌های نمونه تمرین را دارد، نه یک پروژه کامل Gradle؛ چون تنظیمات Gradle و نسخه SDK به محیط نصب‌شده شما بستگی دارد.
