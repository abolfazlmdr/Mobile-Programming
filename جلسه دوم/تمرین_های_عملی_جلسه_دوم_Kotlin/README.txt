تمرین‌های عملی جلسه دوم — برنامه‌نویسی موبایل ۱ (Kotlin)

هر تمرین پوشه جداگانه دارد:
۱) نمایش نام، سن و رشته تحصیلی
۲) بررسی قبولی با شرط if و حداقل نمره ۱۰
۳) نمایش اعداد ۱ تا ۱۰ با for
۴) تابع greet
۵) کلاس Book و ساخت شیء
۶) تفاوت String و String? با مثال
۷) رابط کاربری اندروید با عنوان و دکمه و نمایش Toast

تمرین‌های ۱ تا ۶ فایل‌های مستقل Kotlin هستند. تمرین ۷ فایل‌های Kotlin و XML برای قرار دادن در پروژه Android Studio دارد.
