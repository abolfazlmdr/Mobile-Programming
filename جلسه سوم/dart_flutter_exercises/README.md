# تمرین‌های عملی جلسه سوم - برنامه‌نویسی موبایل با Dart و Flutter

## استاد: سید سعید محمدی

این پوشه شامل پاسخ تمرین‌های عملی جلسه سوم است.

---

## تمرین‌های Dart (۱ تا ۷)

این فایل‌ها را می‌توانید با دستور زیر اجرا کنید (در صورتی که Dart نصب باشد):

```bash
dart exercise1.dart
dart exercise2.dart
# و به همین ترتیب برای بقیه
```

| فایل | توضیح |
|------|--------|
| `exercise1.dart` | ذخیره و نمایش نام، سن و رشته تحصیلی دانشجو |
| `exercise2.dart` | بررسی نمره با دستور if |
| `exercise3.dart` | نمایش اعداد ۱ تا ۲۰ با حلقه for |
| `exercise4.dart` | تابع multiply برای محاسبه حاصل‌ضرب |
| `exercise5.dart` | لیست پنج دانشجو |
| `exercise6.dart` | Map نام و نمره سه دانشجو |
| `exercise7.dart` | کلاس Book با عنوان و نویسنده |

---

## تمرین‌های Flutter (۸ و ۹)

### تمرین ۸
فایل `exercise8_main.dart` را به عنوان `lib/main.dart` در یک پروژه Flutter جدید کپی کنید.

ساخت پروژه جدید:
```bash
flutter create hello_mobile
cd hello_mobile
# محتوای exercise8_main.dart را در lib/main.dart قرار دهید
flutter run
```

### تمرین ۹
فایل `exercise9_main.dart` را به عنوان `lib/main.dart` در یک پروژه Flutter جدید کپی کنید.

این برنامه یک شمارنده دارد که با فشردن دکمه افزایش می‌یابد (StatefulWidget).

---

## نکات

- برای اجرای کدهای Dart خالص، نیاز به نصب Dart SDK دارید.
- برای تمرین‌های Flutter، باید Flutter SDK و یک شبیه‌ساز یا دستگاه واقعی داشته باشید.
- کدها با استانداردهای مدرن Dart و Flutter (Null Safety) نوشته شده‌اند.
