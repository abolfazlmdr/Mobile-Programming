تمرین سوم: صفحه Ionic مدیریت دانشجویان
این دو فایل را در مسیرهای مشخص‌شده در پروژه Ionic مبتنی بر Angular قرار دهید.
ساخت پروژه:
npm install -g @ionic/cli
ionic start StudentManager blank --type=angular
cd StudentManager
npm install
ionic serve
سپس فایل‌های home.page.html و home.page.ts را جایگزین فایل‌های صفحه Home کنید.
این نمونه برای صفحه standalone نوشته شده؛ ساختار پروژه ممکن است با نسخه Ionic تفاوت جزئی داشته باشد.
