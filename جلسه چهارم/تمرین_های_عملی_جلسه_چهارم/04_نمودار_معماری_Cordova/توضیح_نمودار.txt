تمرین چهارم: HTML ساختار صفحه، CSS ظاهر و JavaScript منطق برنامه را می‌سازد. WebView محتوای وب را داخل برنامه نمایش می‌دهد. Cordova Runtime پل ارتباطی JavaScript با بخش بومی است. افزونه‌های بومی درخواست را به APIهای سیستم‌عامل متصل می‌کنند تا با مجوزهای لازم از دوربین، GPS، فایل‌ها و شبکه استفاده شود. فایل architecture.mmd نمودار Mermaid است.
